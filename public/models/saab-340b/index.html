Build progress

A transparent build trail.

This static page is the home for implementation progress, current priorities, and material notes for the Saab 340 B model.

01 In progress

Reference board

Real aircraft references are being grouped by angle, door placement, lighting, propeller geometry, and landing gear stance.

02 Planned

Exterior sculpt

The fuselage, wing roots, nacelles, tailplane, windows, antennas, and service doors will be blocked as a clean static master.

03 Planned

Night lighting pass

Tiny LEDs and diffusers will be mapped before paint so the model has a believable evening-ramp presence.

04 Planned

EFB and navigation layer

Tablet gauge screens, route cues, and integration notes will be gathered here as the build matures.
